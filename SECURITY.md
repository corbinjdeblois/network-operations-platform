# Security policy

This is a lab-first network operations project. It is currently in design; there is no supported production release.

Do not place passwords, keys, real network configurations, workplace inventories, packet/flow captures, or private incident evidence in public issues or pull requests. Public demonstrations use synthetic lab data.

If a security issue involves sensitive information, use the repository's private security-reporting feature once enabled or an established private channel to the maintainer. Private reporting availability has not been verified; check the repository's Security tab before submitting sensitive details. Do not open a public issue containing the sensitive details.

See the [security design](docs/security.md), [data contracts](docs/data-contracts.md), and [production pilot gate](docs/operations/production-pilot.md) for the planned controls. A future release must state its tested versions and supported security-reporting process.
